# AVS Account Security Kernel — Phase 3A Testnet Baseline

## Release status

- **EXPERIMENTAL**
- **BSC TESTNET ONLY**
- **UNAUDITED**
- **NOT FOR PRODUCTION FUNDS**
- **NOT MAINNET READY**
- **RECOVERY WORKFLOW NOT IMPLEMENTED**
- **PAYMASTER NOT IMPLEMENTED**

This release is the public Phase 3A Testnet baseline. It is additive to the
historical Phase 1 and Phase 2 work and does not migrate or replace those
contracts.

## Included security foundation

Phase 3A includes:

- `AVSAccountSecurityKernel`;
- ownerless `AVSAccountAuthority`;
- ownerless `AVSEvolutionController`;
- deterministic `AVSAccountKernelFactory`;
- bounded implementation compatibility;
- deterministic account creation with atomic security-role initialization;
- separate Transaction, Recovery, and Evolution Passkeys;
- canonical EntryPoint v0.8 UserOperations;
- exact authorization, replay, and execution-boundary checks;
- dual-authorized Evolution requests with the immutable delay preserved.

## Known limitation

The deployment documents one Medium WebAuthn limitation: credentials are bound
to the hostname/RP-ID used during registration. A production deployment needs
an explicit RP-ID/origin policy before credentials can be treated as part of a
stable production account model.

## Out of scope

This release does not authorize Mainnet deployment, production custody,
production funds, Phase 3B Recovery, Paymaster operation, or any reduction or
bypass of the Evolution timelock.
